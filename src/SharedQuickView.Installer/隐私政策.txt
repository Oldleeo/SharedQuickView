共享速览隐私政策
版本：2.1　生效日期：2026年9月3日

一、核心结论
共享速览是本地运行的 Windows 工具。当前版本不设置账号系统，不接入广告、统计分析或云端数据库，也不会将剪贴板内容、共享路径或目标 IP 上传给老李Oldlee。

二、本地处理的数据
1. 目标 IP、置顶、悬浮窗、开机启动、剪贴板识别等偏好保存在当前 Windows 用户的 AppData\Roaming\Oldlee\共享速览目录中。
2. “自动识别剪贴板”默认关闭。开启后，软件仅在本机读取新复制的文本，判断其中是否存在可打开内容。网址和本地磁盘路径识别均为独立选项且默认关闭；不符合格式的内容不会执行打开操作。
3. 符合格式的路径会在本机完成 IP 替换，并交给 Windows Shell 访问用户指定的局域网共享目录。网络服务器可能依据其自身策略记录访问日志，这不由本软件控制。

三、联网场景
1. 打开共享目录时，Windows 会连接用户提供的局域网服务器。
2. 用户主动点击版权链接时，系统默认浏览器会访问 https://x.com/oldleeoo。
3. 用户开启网址识别后，系统默认浏览器会访问用户复制或粘贴的 http/https 网址。
4. 当前版本没有自动更新、遥测、崩溃上报或后台数据上传功能。

四、数据保留与删除
1. 关闭软件不会自动删除本地设置。
2. 卸载时可选择是否同时删除个人设置；也可手动删除 AppData\Roaming\Oldlee\共享速览。
3. 软件不会删除或修改共享目录中的文件。

五、权限与安全
安装程序使用管理员权限写入用户选择的安装目录并登记 Windows 卸载信息。开机启动仅在用户安装时勾选或之后于设置中开启时写入当前用户启动项。

本政策用于如实说明当前版本的数据处理方式，不替代特定组织内部的合规评估。若功能发生影响数据处理方式的重大变化，安装界面应展示更新后的政策并重新取得同意。
