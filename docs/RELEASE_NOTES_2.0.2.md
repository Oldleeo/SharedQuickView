# 共享速览 2.0.2

这是共享速览首次公开开源发布。

## 主要功能

- 自动识别 UNC 共享路径并替换目标 IPv4 地址；
- 一次粘贴、多目录批量打开；
- 直接进入路径最后一级目录；
- 转换预览、格式清理和转换后去重；
- 可选剪贴板自动识别与同目标 IP 控制；
- 简洁主界面、桌面悬浮窗和系统托盘；
- 完整设置、开机启动、安装和卸载流程；
- 本地运行，无遥测、无广告、不上传路径或剪贴板。

## 下载说明

下载 `SharedQuickView-Setup-v2.0.2-win-x64.exe` 后运行即可。默认安装到 `C:\Program Files\共享速览`。

公开构建目前没有商业代码签名证书，Windows 可能显示未知发布者或 SmartScreen 提示。请确认下载地址属于 `github.com/Oldleeo/SharedQuickView`，并核对同一发布中的 SHA-256 文件；也可以自行构建源码。

## 系统要求

- Windows 10 或 Windows 11；
- x64 处理器；
- 访问共享目录所需的网络连通性和 Windows/SMB 权限。
