# 共享速览 2.1.0

本版本重点修复了“复制网址时误替换 IP”，并把网址、本地磁盘路径识别做成了用户可选功能。

## 新增

- 可选识别 `http://` / `https://` 网址，使用系统默认浏览器打开；
- 可选识别 `C:\...`、`D:\...` 等本地盘符路径；
- UNC、网址和本地路径可在同一段剪贴板文字中批量识别。

## 默认行为

- 两个新识别选项均默认关闭；
- 网址不再进入 UNC IP 替换逻辑；
- 开启网址或本地路径识别后，它们都会原样打开，不替换 IP。

## 安装

下载 `SharedQuickView-Setup-v2.1.0-win-x64.exe` 后运行即可。默认安装到 `C:\Program Files\共享速览`。
